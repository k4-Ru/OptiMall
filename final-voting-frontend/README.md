# Final Voting Frontend

Simple React frontend for the PHP backend in:

`C:\xampp\htdocs\FINAL VOTING SYSTEM\bscs3b`

## Run

From `C:\OptiMall\final-voting-frontend`:

```bash
npm run dev
```

Then open:

`http://127.0.0.1:5174`

The Vite dev server proxies `/api` requests to:

`http://localhost/FINAL%20VOTING%20SYSTEM/bscs3b/api`

Make sure Apache and MySQL are running in XAMPP before using the app.
